# 长安校区西区路网 v2

`west.json` 是独立绘制的校园布局数据，不包含高德瓦片、截图或实时导航结果。

## 参考资料

- 用户提供的高德西区截图（2026-09-15）：教学区、实验楼、图书馆、湖区、体育区、学生公寓及校门的相对布局。
- [高德：西安邮电大学长安校区西区](https://ditu.amap.com/place/B0FFIWKUF8)
- [学校网站发布的校园平面图，附件 2](https://tg.xupt.edu.cn/__local/4/B5/57/325C3FA943A10CEF88ADEE73B6D_DDAE95D4_93DCD.pdf)

名称用于对应实际校园位置；入口坐标和内部支路是依据上述图示手工建模，未经测绘或通行核验。取餐点设在旭日苑附近，是本系统的业务设定。没有确定名称的水域标作“校园湖”。

## 数据约定

- `places`：23 个配送入口；ID 连续，`nodeId` 指向道路图入口节点。类别用于订单生成和前端筛选。
- `nodes`：81 个道路节点，包含入口、交叉口和转弯处。路口不能直接生成订单。
- `roadChains`：无向可通行道路链；逐段生成图的边。图上没有的连接不允许抄近路。
- `areas` / `labels`：独立绘制的建筑、绿地、水域、运动场和标注，仅用于地图展示。
- `metersPerUnit = 0.7`：教学估算比例，不是从高德测距获得的实测尺度。边长 = 相邻节点欧氏长度 × 该比例。距离、耗时和成本都基于同一估算路网。
- 前端 `roadPath` 与 `legs[].roadPath` 索引 `nodes`；`stops`、`legs[].from/to` 索引 `places`。禁止混用。
- 所有路径先计算道路最短路，再交给 GA 优化停靠顺序；不能跨越湖面、运动场或建筑任意连线。

后续实测时，可以替换坐标、道路连接和比例，并提升 `version`。历史 v1 数据不自动映射到 v2，以免同一 ID 被误解释成另一栋楼；界面会要求重新生成订单。

当前地图不使用高德 SDK，不需要 API Key；页面提供高德原图入口，便于核对。实时骑行权限、封路和精确导航不在该静态数据的能力范围内。
